```markdown
Any Cloud is the modern, unified multi-cloud desktop file manager designed for Windows 11 and Windows 10. Say goodbye to juggling dozens of separate browser tabs and bulky desktop sync clients. Any Cloud connects all your personal and professional cloud storage accounts into a single, blazing-fast, local-first desktop application.

Whether you manage Google Drive, Microsoft OneDrive, Amazon S3, Cloudflare R2, Dropbox, Box, Nextcloud, pCloud, Koofr, or custom FTP/SFTP and WebDAV servers, Any Cloud brings them all under one roof with native Windows performance and elegant Fluent Design aesthetics.

⚡ ULTRA-LIGHTWEIGHT & BLAZING FAST
Built on Tauri 2 and Rust, Any Cloud consumes a fraction of the RAM (<40 MB idle) compared to heavy web or Electron applications. Experience instant app startup and fluid animations.

☁️ 50+ SUPPORTED CLOUD PROVIDERS & PROTOCOLS
Connect seamlessly to:
• Consumer Drives: Google Drive, Microsoft OneDrive, Dropbox, Box, Mega, pCloud, Koofr, Jottacloud.
• Enterprise & S3 Object Storage: Amazon S3, Cloudflare R2, Backblaze B2, Google Cloud Storage, MinIO, Wasabi, DigitalOcean Spaces, Oracle Cloud.
• Protocols & Network Drives: FTP, FTPS, SFTP (SSH), WebDAV, SMB, HTTP, Local Hard Drives.
• Media & Specialized Hosts: ImageKit, Cloudinary, Proton Drive, Internxt, Filen, Yandex Disk, and more.

🔄 DIRECT CROSS-CLOUD TRANSFERS
Copy or move files and folders directly between different cloud providers without messy manual downloads. Multi-threaded transfer engine with live progress, transfer speed calculation, ETA, and intelligent conflict resolution (Replace, Skip, Keep Both).

🔒 100% LOCAL-FIRST & ZERO-RELAY PRIVACY
Your data belongs exclusively to you. Any Cloud features a zero-relay architecture—there are no middleman servers or proxies. All credentials, API tokens, and passwords are stored safely on your local device. File contents stream directly point-to-point between your computer and your cloud providers.

⚡ INSTANT LOCAL CACHING & OFFLINE SEARCH
Every visited folder is indexed locally in SQLite with WAL mode. Browse folder structures instantly in <5ms, even when offline, and search files across all your connected clouds simultaneously with FTS5 full-text search.

Designed to look right at home on modern Windows:
• Deep dark mode and crisp light mode.
• Acrylic translucent glassmorphism.
• Dual view modes: Visual Thumbnail Grid and Detail List view.
• Seamless navigation with Back, Forward, Up buttons, interactive breadcrumb path bar, and mouse extra buttons (Mouse 4 & Mouse 5).
```
